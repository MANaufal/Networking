>Closest layer to the user — where applications access network services

- Provides the interface between an app (browser, email client) and the network
- Examples: **HTTP/HTTPS, FTP, SMTP, DNS, DHCP, SSH, Telnet**
- Note: L7 is **not the app itself** — it's the protocols the app uses to talk over the network
- L7/L6/L5 data is simply called **Data** (vs Segment L4, Packet L3, Frame L2, Bits L1)
