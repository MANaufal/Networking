>Devices that sends or receives traffic

- Clients are the device that receive traffic
- Servers are the senders. It's just a computer with webserver app that can communicate with.
- Any device with an **IP address** on the network is a host (laptops, phones, printers, servers, IoT...)
- Roles are **relative to a single conversation**:
	- Client **initiates** the request, server **listens** and responds
	- The same device can be a client in one conversation and a server in another
- Servers run software that listens on **specific ports** (e.g. web server on 80/443)
- Every host needs a **NIC** (Network Interface Card) with a MAC address to connect
