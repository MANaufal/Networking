>Facilitates communication **within** a network

>**Switching is the process of moving data *within* networks**.
- Devices communicating through a switch **always** belong to the same IP network.
- **Switches** are L2 devices, they only use L2 header (MAC address) to make decisions
>Switches have a MAC address and can be configured to have IP Address to act as a host

>Switches use and maintain MAC Address Table
- Mapping of Switch Ports to MAC addresses

>Switches only perform 3 actions
- **Learn:** Update MAC Address Table with Source MAC
- **Flood:** Duplicates and send frames to every switching ports beside source ports
- **Forward:** Use MAC Address Table to send frame to appropriate ports
